# إنجليزي عملي (English Coach)

تطبيق ويب لتعلّم الإنجليزي العملي للعرب، من A1 لـ C1، والشرح كله بالعربي:

- 🧭 **اختبار تحديد مستوى** (20 سؤال) بيقترح المستوى المناسب لك، و📈 **مسار A1 ← C1** فيه تقدّمك بكل مستوى.
- 🃏 **155 كلمة بالتكرار المتباعد (SM-2)** موزعة على المستويات والمواضيع، منها كلمات متقدمة للشغل والدراسة (B2 وC1).
- ✍️ **كتابة وترجمة:** 30 جملة بتترجمها من العربي للإنجليزي، والتصحيح بيقبل الاختصارات (I'm = I am) ويسامح بغلطة إملائية صغيرة. وفي كمان **6 مهام كتابة** (رسائل وفقرات) مع قائمة تحقق ونموذج جواب.
- ⭐ **كلماتي:** ضيف كلماتك وجملك الخاصة، وبتدخل بالمراجعة الذكية.
- 📘 **24 درس قواعد** من A1 لـ C1 بشرح عربي، و144 تمرين: اختيار، وكتابة، وترتيب جمل.
- 🔊 **نطق** بصوت المتصفح، و🎤 **تجربة النطق** (Chrome وEdge).
- 🎯 **تدريب سريع** مختلط: كلمات، وإملاء، وقواعد، وترجمة.
- 💬 **33 جملة جاهزة** حسب الموقف.
- 🔥 **نقاط، وسلسلة أيام، وهدف يومي (30 نقطة)، وشكل فاتح وداكن.**
- يشتغل بدون سيرفر، والتقدّم محفوظ بالمتصفح.

**التشغيل:** افتح `app/index.html` بالمتصفح (Chrome أو Edge لأفضل صوت).

**للمطوّرين:**
- `node --test tests/core.test.js` (منطق التطبيق).
- `node ../_devtools/ui-check.js dev/ui-checks/app.json` (فحص الواجهة).
- المحتوى بـ `app/data.js`، والمستويات والكتابة بـ `app/data_levels.js`.
