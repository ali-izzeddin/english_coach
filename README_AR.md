# إنجليزي عملي (English Coach)

تطبيق ويب لتعلّم الإنجليزي العملي للعرب، والشرح كله بالعربي:

- 🃏 **كلمات بالتكرار المتباعد (SM-2):** 100 كلمة بخمس مواضيع (الشغل والفريلانس، وتقييم الذكاء الاصطناعي، والتقنية، وخدمة العملاء، والحياة اليومية).
- 🔊 **نطق** بصوت المتصفح، و🎤 **تجربة النطق** (Chrome وEdge).
- 📘 **12 درس قواعد** بشرح عربي و72 تمرين: اختيار، وكتابة، وترتيب جمل.
- 🎯 **تدريب سريع** مختلط فيه إملاء (تسمع وتكتب).
- 💬 **33 جملة جاهزة** حسب الموقف.
- 🔥 **نقاط ومستويات وسلسلة أيام وهدف يومي (30 نقطة).**
- يشتغل بدون سيرفر، والتقدّم محفوظ بالمتصفح.

**التشغيل:** افتح `app/index.html` بالمتصفح (Chrome أو Edge لأفضل صوت).

**للمطوّرين:**
- `node --test` (منطق التطبيق).
- `node ../_devtools/ui-check.js dev/ui-checks/app.json` (فحص الواجهة).
- المحتوى كله بـ `app/data.js`.
